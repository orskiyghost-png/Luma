# BUILD_PLAN.md — запросы для агента по порядку

Как этим пользоваться: копируйте **один блок** целиком (от "Прочитай..." до
конца блока) и отправляйте агенту. Ждите, пока агент закончит и отчитается.
Только после этого берите следующий блок. Не пропускайте фазы и не
объединяйте несколько блоков в один запрос — так агенту проще проверять себя
и не ломать предыдущую работу.

Каждый блок начинается одинаково — с просьбы прочитать инструкции и журнал
прогресса. Это подстраховка на случай, если агент "забыл" контекст между
сессиями.

3. Создай .env.example со списком нужных переменных (без значений) и убедись,
   что .gitignore исключает все файлы с реальными секретами.
4. Создай docs/PROGRESS.md и сделай в нём первую запись.
5. Скажи мне простыми словами, какие ключи/доступы тебе от меня нужны на
