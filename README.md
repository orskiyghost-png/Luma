# Карта-соцсеть (рабочее название)

Социальная сеть на основе карты: метки-заметки с категориями и TTL, реакции,
личные сообщения, опциональный показ пользователей на карте (только 18+,
строго по согласию). Подробное ТЗ — в `docs/AGENT_INSTRUCTIONS.md`.

## Технологии

- **Frontend:** Next.js (React) + TypeScript, Tailwind CSS + shadcn/ui
- **Карта:** MapLibre GL JS + бесплатные тайлы (MapTiler / OSM)
- **Backend/БД:** Supabase (Postgres + PostGIS, Auth, Realtime, Storage)
- **Капча:** Cloudflare Turnstile
- **Хостинг:** Vercel + Supabase (бесплатные тарифы на старте)

## Структура репозитория

```
/app                — страницы и роуты Next.js
/components         — переиспользуемые UI-компоненты
/lib                — вспомогательная логика (клиент Supabase, утилиты)
/lib/supabase       — типы и запросы к БД
/supabase/migrations— SQL-миграции схемы БД (версионируются в git)
/docs               — инструкции, план сборки, журнал прогресса
env.example         — список нужных переменных окружения (БЕЗ значений)
```

## Для разработчиков/агентов

- Правила работы: `docs/AGENT_INSTRUCTIONS.md`
- План по фазам: `docs/BUILD_PLAN.md`
- Текущее состояние: `docs/PROGRESS.md`
- Передача новому агенту: `docs/AGENT_HANDOFF.md`

## Переменные окружения

Имена всех нужных переменных — в `env.example`. Реальные значения хранятся
только в переменных окружения хостинга (Vercel) и в настройках Supabase —
никогда в коде и никогда в истории git.
